# 用户管理和权限控制功能补充文档

## 1. 文档概述

### 1.1 背景说明
根据产品需求文档分析，SMS营销数据分析系统当前在用户管理和权限控制方面存在严重缺失。本文档旨在补充完整的用户认证、权限管理、账号管理等核心安全功能，确保系统符合5人高效小团队的使用场景。

### 1.2 设计原则
- **最小权限原则**：用户只能访问其角色所需的最小权限范围
- **职责分离**：管理员负责系统配置，操作员负责日常业务操作
- **安全优先**：所有操作都有审计日志，敏感操作需要二次确认
- **简化管理**：适合5人小团队，避免过度复杂的权限设计

### 3.3 权限验证机制

#### 3.3.1 前端权限控制
```typescript
// 权限检查Hook
const usePermission = () => {
  const { user } = useAuth();
  
  const hasPermission = (permission: string) => {
    if (!user) return false;
    return user.permissions.includes(permission);
  };
  
  const isAdmin = () => user?.role === 'admin';
  const isOperator = () => user?.role === 'operator';
  
  return { hasPermission, isAdmin, isOperator };
};

// 权限保护组件
const ProtectedComponent = ({ permission, children }) => {
  const { hasPermission } = usePermission();
  
  if (!hasPermission(permission)) {
    return <div>权限不足</div>;
  }
  
  return children;
};
```

#### 3.3.2 后端权限验证
```typescript
// 权限中间件
const requirePermission = (permission: string) => {
  return (req, res, next) => {
    const user = req.user;
    
    if (!user || !user.permissions.includes(permission)) {
      return res.status(403).json({ error: '权限不足' });
    }
    
    next();
  };
};

// API路由保护
app.delete('/api/packages/:id', 
  authenticateToken,
  requirePermission('package.delete'),
  deletePackage
);
```

#### 4.3.2 特殊保护机制
```typescript
// 角色变更前检查
const validateRoleChange = (userId: string, newRole: string) => {
  const currentAdmins = users.filter(u => u.role === 'admin' && u.status === 'active');
  const targetUser = users.find(u => u.id === userId);
  
  // 不能删除最后一个管理员
  if (targetUser.role === 'admin' && newRole !== 'admin' && currentAdmins.length === 1) {
    throw new Error('不能删除最后一个管理员账号');
  }
  
  // 管理员数量限制
  if (newRole === 'admin' && currentAdmins.length >= 3) {
    throw new Error('管理员账号数量已达上限（3个）');
  }
  
  return true;
};
```

#### 7.1.2 权限验证流程
```typescript
// API权限验证中间件
const apiAuthMiddleware = async (req, res, next) => {
  try {
    // 1. 提取Token
    const token = extractToken(req);
    if (!token) {
      return res.status(401).json({ error: '缺少认证信息' });
    }
    
    // 2. 验证Token
    const payload = verifyJWT(token);
    const user = await getUserById(payload.userId);
    
    // 3. 检查用户状态
    if (user.status !== 'active') {
      return res.status(403).json({ error: '账号已被禁用' });
    }
    
    // 4. 检查权限
    const requiredPermission = getRequiredPermission(req.path, req.method);
    if (!user.permissions.includes(requiredPermission)) {
      return res.status(403).json({ error: '权限不足' });
    }
    
    // 5. 记录API调用
    await logAPICall(user.id, req.path, req.method);
    
    req.user = user;
    next();
  } catch (error) {
    return res.status(401).json({ error: '认证失败' });
  }
};
```
